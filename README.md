### 🧠 About Me

I'm an **Electrical & Electronics** background developer who fell in love with what happens *underneath* the code — memory, pointers, bits, and bytes. I like building things from scratch instead of importing a library for it: linked lists that hold billion-digit numbers, custom file parsers, and low-level data hiding — because understanding the "how" matters more to me than just the "what."

- 🔧 I build things in **pure C** — no shortcuts, no black boxes
- 🧮 Currently exploring **arbitrary precision arithmetic**, **memory management**, and **embedded/Linux fundamentals**
- 📚 Always learning: **data structures, systems programming, and how computers *actually* work**
- 💬 Ask me about: pointers, linked lists, low-level file formats, or why segfaults happen
- ⚡ Fun fact: I'd rather write my own algorithm than `#include` someone else's

### 🛠️ Featured Projects

| Project | What it does |
|---|---|
| 🧮 **[APC — Arbitrary Precision Calculator](https://github.com/Manju735/APC)** | A custom big-number calculator built with doubly linked lists — adds, subtracts, multiplies & divides numbers *way* beyond `long long` range, with zero overflow. |
| 🕵️ **[Steganography](https://github.com/Manju735/Steganograpy)** | Hides secret data inside image/file bytes — a hands-on dive into bitwise manipulation and file I/O. |
| 🎵 **[MP3 Tag Reader](https://github.com/Manju735/Mp3_tag_reader)** | Reads and extracts ID3 metadata (title, artist, album) directly from raw MP3 binary data. |
| 📇 **[Address Book Project](https://github.com/Manju735/address-book-project)** | A C-based contact manager exploring structured data storage, CRUD operations, and file persistence. |

> 🔍 Notice a pattern? Every project here is about **taking raw bytes and making them meaningful** — that's the thread running through everything I build.
